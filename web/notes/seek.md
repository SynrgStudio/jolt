Jolt's search, for Claude Code, Codex, Cursor and any agent that speaks MCP.

[Seek](https://seek.synrgs.tech) is an MCP server that lets AI agents find names on every drive in milliseconds, search text inside a folder's files and PDFs, and know what you changed lately. With Jolt installed it uses Jolt's index and fuzzy matching, and ranks the folders you open in Jolt higher. It only reads, never looks in private places, and logs every call. Its website has the benchmarks against Everything, fff and ripgrep, and how it works.
