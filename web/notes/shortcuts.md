<!-- From Jolt 0.5.0's docs page. -->

111 commands (the `commands` fact). Every one can be changed: click its shortcut in Ctrl+K and press the new key (Del removes it, Esc cancels), or edit `[shortcuts]` in `config.txt`.

|  |  |
|---|---|

This table is generated from Jolt's source on every deploy, so it always matches the current version. Fixed keys that can't be changed: the arrows, PageUp/PageDown, Home/End, Esc, Ctrl+Space, Ctrl+1…9 (favorites) and Alt+1…9 (tabs). Mouse: see the basics; Ctrl++ / Ctrl+- / Ctrl+0 change the size of the whole interface.

The full table, generated from `src/config.inl` of 0.5.0, is `data/shortcuts.csv`: the command's name, its default keys (empty: none, it can be given one in Ctrl+K) and what it does.
