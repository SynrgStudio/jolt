Every planned feature is an [issue](https://github.com/SynrgStudio/jolt/issues), tagged by area. Each one lands as its own pull request.

Coming up, among others: archives, a helper for Open/Save dialogs, more preview formats, and a light theme. If something you need isn't there, open an issue.
