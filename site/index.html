Jolt

The file explorer for Windows that keeps up with you.

Folders open instantly. One small file, no dependencies, no telemetry.

Get Jolt

One file. The same jolt.exe is the program and the installer.

  1. Download jolt.exe. It isn't signed yet, so Windows SmartScreen may warn you the first time: More info → Run anyway. See Privacy & signing.
  2. Open it from anywhere. It offers to install itself to %LOCALAPPDATA%\Jolt, for your user only, with no administrator rights.
  3. In the install panel (☰ → Install) you can turn on Add to PATH (type jolt in any terminal), Default file explorer (folders open with Jolt; what was there before is saved and comes back if you turn it off) and Start with Windows (starts hidden, ready for the shortcut).

Updating is the same: open a newer jolt.exe and press Update. To uninstall, use ☰ → Install → Uninstall, Windows Settings → Apps, or jolt.exe --uninstall. Your settings and favorites stay in %APPDATA%\Jolt.

Win+E. Windows doesn't give up its own shortcut, so Jolt installs a handler for it when it is the default explorer. The global shortcut Win+J works from anywhere regardless.

Always ready

Closing the window hides it. Jolt stays open and comes back instantly.

  • Win+J from any app shows Jolt; if it is already in front, hides it. With File Explorer in front, it opens that folder in Jolt. Change the key with global_hotkey.
  • The tray icon does the same with a click; right click to quit.
  • jolt.exe C:\some\folder opens the folder in the running instance (a new tab, or the tab that already has it).
  • ☰ → Quit or jolt.exe --quit really close it. jolt.exe --hidden starts without showing the window.

Options in config.txt: run_in_background, global_hotkey, tray_icon, open_drives (open USB sticks as soon as they are plugged in).

It works like a commander: the keyboard does everything, the mouse does the same.

On close, Jolt saves each pane's tabs, the split, the preview, the window position, the sidebar and the sort order, and restores them next time.

Sidebar

Ctrl+B, or the button left of the tabs, shows and hides it.

  • Favorites: Ctrl+D adds or removes the current folder; Ctrl+1…9 jumps to one. Drag to reorder, or drag any folder onto the list to add it; right click to rename or remove. Saved in %APPDATA%\Jolt\favorites.txt as Name|Path lines.
  • Drives: hover one and its row turns into the usage bar with free and total space, updated every second.
  • Recents: sorted by how much you use them, not by last opened. A folder earns a point when you stay at least 1.5 s, and its heat halves every 30 days. recents = 0 in config.txt hides the section.

Find things

Three ways: type in the folder, search its subfolders, or search every drive.

Type to filter

Just start typing in any folder. It filters fuzzily, like fzf: rpt finds report.pdf, accents are ignored, and the best matches rise to the top. Backspace edits, Esc clears. Letters that are configured as shortcuts don't filter. See filter terms for narrowing by extension, size or date.

Ctrl+Shift+F — search subfolders

The same filter, over the whole folder and everything inside it. Results show where each one is; Ctrl+Shift+E opens the folder of the highlighted result. Esc goes back.

Ctrl+P — go to anything

Recents, favorites, system places, drives and everything on your drives, with fuzzy search. Typing a path (C:\Us…, %APPDATA%, ~) autocompletes its folders. Enter opens, Ctrl+Enter opens in a new tab.

Behind it is an index of the fixed drives, saved in %LOCALAPPDATA%\Jolt\index-X.bin: available at once on startup, kept up to date while Jolt runs, and rebuilt in the background at low priority when it is older than 12 hours. Walking a large drive without elevated rights takes a few minutes the first time; Ctrl+K → Reindex the drives now asks for administrator rights once and reads the drive's own table (the MFT, like Everything does), which takes seconds.

Filter terms

Plain words stay the fuzzy pattern. The other terms narrow the list, in any folder and in subfolder search.

TermMeaning
.png   *.png   ext:png,jpgextension (several: any of them)
>10mb   <500kb   >2gbsize. A bare number is MB. Folders have no size and are left out
type:folder   type:filekind
newer:7d   older:2w   modified:todaydate: d h w m y, or today (since midnight)
!tmp   !.bak   !*.logexclude by name, extension or pattern
report*.pdf   ?.txtwildcard pattern on the name
content:word   content:"two words"search inside the files: keeps the text files whose content has it, and shows the line around the match next to the name. Files are read in the background (UTF-8, UTF-16 or the system code page; binaries and files over 32 MB are skipped). With Ctrl+Shift+F it covers the subfolders too
tag:urgent   !tag:doneitems with (or without) a tag

Typos are forgiven. Names close to what you typed appear under the real matches, with how close they are in grey next to the name: filepocker finds filepicker at 90%, and swapped letters stay at 100% (filepikcer). It works in subfolder search, Ctrl+P and Ctrl+K too. filter_typos in config.txt sets the lowest percentage, 75 by default, or no to turn it off.

Examples: content:TODO .cpp — source files with a TODO.   invoice .pdf newer:30d — the invoices of the last month.   >500mb !.iso — what is taking space, except disc images.   type:folder old — folders with "old" in the name.

Only the words light up in the names. The status bar shows how many match.

Preview

Space opens a panel on the right that follows the cursor.

  • Images with their EXIF orientation, text and code with syntax highlighting (C-family, JS/TS, C#, Java, Go, Rust, Swift, Kotlin, PHP, Python, shell, PowerShell, batch, Lua, Ruby, SQL, CSS, HTML/XML, JSON, YAML, INI/TOML, Markdown, diffs, Dockerfile, Makefile), with line numbers and long lines wrapped (preview_wrap = no in config.txt, or the palette's "wrap long lines", turns that off), the contents of a folder, and the Shell thumbnails of anything else: PDF, videos, Office documents, executables' icons at full size.
  • Below it: type, size, modified date, and the dimensions of images or the number of items in a folder.
  • Wheel scrolls. Drag its left edge to change the width; double click the edge to reset it. The width is saved.

Working with files

Everything goes through Windows' own machinery, so progress, conflicts and the Recycle Bin behave as in File Explorer. Then Jolt adds undo on top.

Ctrl+C / Ctrl+X / Ctrl+Vcopy, cut and paste, compatible with File Explorer both ways. Pasting in the same folder makes a copy with another name
Ctrl+V with an image or text on the clipboardsaves it in the folder as a PNG (keeping transparency) or a UTF-8 .txt, named by the moment and ready to rename
drag and dropbetween Jolt's folders, panes, tabs, favorites and drives, and from or to other apps. Same rules as File Explorer: Ctrl copies, Shift moves
Ctrl+N / Ctrl+Shift+Nnew file / new folder, ready to rename
Ctrl+Shift+Dduplicate ("name - Copy.ext")
Ctrl+Shift+Ggroup in a new folder: moves the selection into a new folder next to it (named after the item if there is one) and starts renaming the folder
Del / Shift+Delto the Recycle Bin / delete permanently (with Windows' own confirmation)
Ctrl+Shift+C / Ctrl+Alt+Ccopy the path (quoted only if needed) / copy just the name. "Copy the path with forward slashes" is in the palette
Alt+Rfolder sizes: calculates every folder in the list, or the selected ones. Subfolders get calculated too, sorting by size uses them, and they are remembered between sessions
Alt+EnterWindows properties
Ctrl+Alt+T / Ctrl+Alt+Eopen a terminal (Windows Terminal, or cmd) / File Explorer in this folder
right click / Shift+F10 / Menu keythe Windows context menu for the file, the folder or the background; with Shift, the extended one. See context menu

Tags and colors

Right click → Tags, or Ctrl+K → "tag", puts a label on the selection: pick a known one or type a new name. Each tag gets a color and shows as a little tag-shaped label after the name, with its name inside while there is room (a dot when there isn't, and in the grid's corner), and in the preview's info; an item can have several. tag:urgent in the filter keeps the tagged items, !tag:done leaves them out, in subfolder search too. They are saved in %APPDATA%\Jolt\tags.txt, which can be edited by hand (name = RRGGBB under [tags] sets a color), and they follow renames done from Jolt.

Names can also take a color by rule, in config.txt:

[file_colors]
.jpg .png .gif .webp = 7FB3FF
.zip .7z .rar = C9A86A
*backup* *.bak = E06C75
folders = E6B450

Undo

Ctrl+Z undoes and Ctrl+Y (or Ctrl+Shift+Z) redoes what was done from Jolt in this session, up to 100 steps: rename, move, copy, duplicate, create, group, paste and send to the Recycle Bin. It never overwrites anything or touches what changed afterwards, and what it removes goes to the Recycle Bin. It doesn't cover what replaced or merged with something that already existed, or permanent deletion.

Status bar

Item count and total size of the folder (folders count once their size has been calculated). With several items selected, their count and size too. While filtering, how many match.

Rename

One item inline, or many at once with a preview.

F2 — one item

The name without the extension is selected. Tab / Shift+Tab save and move on to renaming the next / previous item, so a column of files can be renamed without leaving the keyboard.

F2 with several selected, or Ctrl+F2 — many at once

A panel shows every result before anything is renamed. Invalid names, names already taken and repeated results are marked in red, and Rename stays off until they are fixed. Enter renames, Esc cancels, Tab moves between the boxes, and Ctrl+Z takes the whole batch back in one step. Shifts like 1 → 2 → 3 go through temporary names, so nothing collides.

New name is a pattern:

{name}   {name:lower}   {name:upper}   {name:title}the name without its extension, as is or with its case changed ({NAME} and {Name} work too)
{ext}   {ext:upper}the extension, with its dot
{n}   {n:3}   {n:3:10}   {n:3:10:5}a counter: padding, start, step. {n:3:10:5} gives 010, 015, 020…
{date}   {date:YYYYMMDD_hhmm}   {time}   {created}modified or created date, as YYYY-MM-DD or with a format made of YYYY YY MM DD hh mm ss
{parent}the folder's name
{random}   {random:12:letters}   {random:6:digits}   {uuid}random text, drawn once per item so the preview holds still

Find / Replace runs on the name before the pattern: plain text replaces every occurrence, ignoring case; /regex/ uses a regular expression, with $1 $2 for its groups in Replace.

Examples: Trip {n:2}{ext} — Trip 01.jpg, Trip 02.jpg…   {date}-{name}{ext} — the date in front.   Find /^IMG_(\d+)/, Replace photo-$1 — IMG_0042.jpg becomes photo-0042.jpg.   {name:title}{ext} — Title Case.

Views

Sort, group and filter each folder its own way. Rules apply instantly and are remembered.

The filter button left of "Name" (or Ctrl+K → View for this folder) opens the rules, Notion style: Sort by (name, date, size, type; several rules act as tiebreakers), Group (by day, month, type or extension: the list splits into titled sections you can collapse), Folders (first, last, mixed) and Show only / Hide (name contains, extension is, newer or older than N days, larger or smaller than N MB, folders, files, hidden). Rules are reordered by dragging their handle.

At the top you choose All folders or Only this folder (with and its subfolders to apply it to everything inside). When a folder has its own view, the button turns blue. Clicking the column headers changes the sort order of that view. They are saved in %APPDATA%\Jolt\views.txt, which can be edited by hand and reloads itself:

[all]
folders = name
sort = date desc

[C:\Users\me\Downloads]
subfolders = no
sort = name asc
group = day
folders = first
hide = extension tmp part crdownload

List or grid

Each folder can be a grid of thumbnails instead of a list. Ctrl+Alt+wheel up makes the cells bigger (80 to 256 px), down goes back to the list; the palette has the same as commands. In the grid, the arrows walk the cells, and everything else works as in the list: typing filters, box select, drag and drop, the preview. The thumbnails come from the Shell (photos, videos, PDF, Office, and the icon for the rest) and are cached on disk, so a folder you have seen opens with its pictures already there. It is saved per folder in views.txt as layout = grid 144.

Quick toggles in the palette (Ctrl+K): show or hide folders, files, hidden files (Ctrl+H) and extensions; group this folder by day or type; collapse or expand all groups; sort by type; more or less space between rows. Any of them can get a key with a click.

Custom commands

Your own entries in the palette and the context menu, from config.txt.

[commands]
Open in VS Code = code "{dir}"
Edit with Notepad = notepad "{file}"
PowerShell here = wt -d "{dir}" powershell
Compress = "C:\Program Files\7-Zip\7z.exe" a "{name}.zip" {files}

[shortcuts]
open in vs code = Ctrl+Alt+V
  • {file} is the highlighted item, {files} everything selected (each quoted), {dir} the folder, {name} the item's name.
  • The first word is the program, the rest its arguments. It runs in the folder, and a bare name is found in PATH.
  • They appear in Ctrl+K, where a click on the row assigns a key, and at the end of the right-click menu, where the menu editor can hide or move them like any other entry.
  • A # starts a comment anywhere in config.txt, so it can't be part of a command.

Configuration

Plain text files in %APPDATA%\Jolt. Each one reloads itself when saved.

config.txtgenerated the first time with every value and a comment. [general]: font, size, row height, sidebar and preview width, hidden files, folders_first (yes / no / name), background, hotkey, tray. [columns]: which columns and their widths (drag the column edge in the app). [colors]: every interface color in RRGGBB. [shortcuts]: one command per line with its keys. [commands]: your own commands. Deleting an option returns it to its default
favorites.txtName|Path, one per line
views.txtthe views per folder
menu.txtthe context menu order and hidden entries
tags.txtthe tags: their colors and which items have them
session.txt, recents.txttabs and window, and the recent folders with their heat
%LOCALAPPDATA%\Joltthe installed program, the drive index, the calculated folder sizes (sizes.bin) and the thumbnail cache (thumbs\, safe to delete)

☰ → Configuration folder opens it. With JOLT_DEBUG=1 in the environment, Jolt writes a log to %TEMP%\jolt.log.

Context menu

The real Windows menu, with your extensions, drawn by Jolt and trimmed by you.

☰ → Context menu… opens an editor that shows the menu for three contexts (folder background, file, folder) and lets you hide entries (checkbox) and reorder them (drag, or Ctrl+↑/↓). Saved in menu.txt:

[background]
-anycode              ← hidden
git_shell
---                   ← separator
properties

Each entry is identified by its verb (the gray column in the editor). Whatever isn't listed is added at the end in the order Windows gives it. Submenus can't be customized yet. Delete goes through Jolt so it stays in the undo history.

Privacy & signing

Jolt doesn't connect to the network. It will not transfer any information to other systems unless you ask it to. There is no telemetry, no update check, no account. This site makes no third-party requests either.

Releases are built by GitHub Actions from the repository's source, on GitHub's machines, and each one lists its SHA-256. They aren't signed yet: the plan is to apply to the SignPath Foundation, which offers free code signing to open source projects, once Jolt is more widely used. Until then SmartScreen may warn on first run.

Jolt is free software under the GNU GPL v3: use it, change it, share it, as long as a modified version you distribute publishes its source under the same license.

For developers

C++20, Win32 and Direct2D/DirectWrite. No external dependencies, one executable.

How it stays fast

  • Lists with NtQueryDirectoryFile in 64 KiB batches, on a separate thread.
  • Every visited folder stays in memory; going back shows it instantly and rechecks it in the background.
  • Watches the current folder and updates itself when something changes.
  • Preloads the highlighted folder (local drives) so Enter doesn't have to read the disk.
  • Icons that depend only on the extension are resolved on the spot; those that depend on the file (folders, .exe, shortcuts) come from another thread, for visible rows only.
  • Draws only what is visible.
  • Shell thumbnails are made on a thread and cached on disk (%LOCALAPPDATA%\Jolt\thumbs, PNG, by path, size and modified time; entries unused for 60 days are dropped), so the preview is instant the second time.

Build

build.bat           optimized (/O2)          ~2 s
build.bat fast      unoptimized (/Od)        ~1 s, for iterating
build.bat clean     deletes build\

Requires Visual Studio 2022 with the C++ workload. Produces build\jolt.exe and build\bench.exe. The first build saves the compiler environment in build\env.bat and generates the precompiled header (src\pch.h); if you add a system header, put it there and run build.bat clean. bench.exe <folder> compares the listing APIs.

Test mode

jolt.exe --test script.txt [--output folder] runs Jolt without a window: it draws into a bitmap, runs the script and saves PNG captures, using a copy of the configuration in %TEMP%\jolt-test\data so nothing of the user's is touched. Steps, one per line:

go C:\folder        key Ctrl+Shift+F      type text          command show_folders
click 300 118       double x y            right x y          wheel x y -3
press x y           drag x y              release x y        hold Alt / hold none
wait 300            capture name.png      size 1100 700      echo text
selection           rows                  message            exists C:\a.txt
touch C:\a.txt      open_path C:\x        select_path C:\x   rename_preview
usage_set path | points | days            measure 300        quit

Every feature on this page was checked this way before it shipped. With --test-desktop the same runs on a separate Windows desktop, so system dialogs (properties, copy conflicts) stay out of sight; extra steps drive those windows by their text through UI Automation.

Release

Bump src/version.h and push to master: GitHub Actions builds, tags and publishes the release, with the SHA-256 in the notes. The latest build is always at github.com/SynrgStudio/jolt/releases/latest/download/jolt.exe. This site is published from site/ by the same kind of workflow.
